Executive Summary

  • Carnegie Mellon leads several works on language-driven robot control, including closed-loop code replanning for manipulation and benchmarks for robust trajectory prediction.
  • Multiple papers advance manipulation robustness and safety, from multimodal intent preservation and residual policy adaptation to plug-and-play force control and specification-grounded safety evaluation.
  • Navigation and planning see progress via Dijkstra-as-oracle online SSP planning, scale-consistent monocular SLAM, hybrid terrain-aware planning, and efficient embodied VLN with VLMs.
  • Whole-body and humanoid control are pushed forward by sim-to-real loco-manipulation, brachiation via waypoint-guided RL, and stereo-augmented humanoid VLA architectures.
  • New benchmarks, datasets, and frameworks (ManiGuard, PROBE, PRISM, LIBERO-VIFO, ControlledShifts, PDDL-ART, TGL) focus on standardized evaluation, safety, and scalable long-horizon skill acquisition.
  • Several works target safety and reliability at deployment time, including predictive safety shields with JEPA, recovery-aware GRPO variants, test-time augmentation diagnostics, and calibrated risk modeling.

VLCP: Vision Language Control Policy Closed-Loop Code Replanning for Robot ManipulationCarnegie Mellon UniversityKeeps a powerful VLM frozen and has it write short Python control functions for manipulation, then repeatedly rewrites this code within an episode based on multi-view observations. On 57 MuJoCo/RoboVerse tasks, this training-free, code-replanning policy achieves a 10x success boost over single-shot prompting and builds a reusable skill library across episodes.Link
ControlledShifts: Towards Standardizing Robustness Evaluation in Trajectory Prediction Under Distribution ShiftsCarnegie Mellon UniversityIntroduces a framework that resplits existing autonomous-driving trajectory datasets into matched in- and out-of-distribution partitions along controlled axes of variation. Defines three benchmarks and a unified robustness score to jointly assess prediction quality and stability, revealing differing robustness behaviors of transformer-based predictors under distribution shift.Link

Dijkstra as an Oracle for Online Stochastic Shortest Path Navigation with Provable GuaranteesShows that Dijkstra’s algorithm can exactly solve certain stochastic shortest path problems via a reduced-cost condition, enabling fast planning with theoretical guarantees. Builds DORA, an online learner for navigation that repeatedly queries a shortest-path oracle without learning transition kernels, achieving near-optimistic value iteration performance with far less planner work and sharply reduced unsafe contacts.Link
Scalix: Uncertainty-Aware Scale-Consistent Monocular SLAMProposes a monocular SLAM system that injects learned depth with per-pixel and per-frame scale uncertainty into a factor-graph, treating scale as an independent measurement. This yields metric, scale-consistent trajectories in real time, achieving state-of-the-art results on indoor/outdoor benchmarks while retaining robustness and generalization.Link
Embodied-Navigator: Point, Think, Memorize, and Align for Efficient NavigationIntroduces TAMP-Nav, which has VLMs output 2D pixel points that are projected into 3D actions, aligning navigation control with 2D pretraining priors. A selective reasoning and anchor-trajectory memory plus a two-level GRPO alignment scheme yields state-of-the-art embodied navigation performance with high sample and runtime efficiency.Link
Terrain-Aware Local Path Planning with Global DEM Data Integration for Autonomous UGV NavigationCombines coarse global paths from DEM-based A* with local LiDAR-driven obstacle and terrain analysis to adapt paths online for UGVs. In simulation, the hybrid planner substantially increases obstacle avoidance and reduces traversed slope, improving safety and efficiency in complex outdoor terrain.Link
Jetson-ORB-SLAM3: Accuracy-Preserving GPU Implementation for Edge Computing DevicesPorts ORB-SLAM3’s visual front end to the Jetson Orin Nano GPU while preserving keypoints and descriptors nearly identically to the CPU reference, and accelerates learned loop closure via native TensorRT. Achieves desktop-level trajectory accuracy across EuRoC, TUM-VI, and KITTI while sustaining real-time performance and enabling place recognition on a 7W edge platform.Link
PROBE: Manipulation-Grounded Visual Question Answering with VLM AgentsDefines Manipulation-Grounded VQA, where robots must physically manipulate clutter to reveal occluded objects before answering questions, and introduces PROBE-Sim and PROBE-Bench as a simulation and benchmark suite. Shows that agentic, tool-using VLMs outperform perception-only baselines and that finetuned PROBE-Agents transfer to real tabletop manipulation scenarios.Link
Effector-Centric NMPC of Tiltable-Multirotors for Offset-Free Omnidirectional Aerial ManipulationAnalyzes tiltable-multirotor designs and presents an effector-centric nonlinear MPC framework that exploits wrench redundancy and handles singularities and disturbances. Runs fully onboard at 100 Hz on a custom tiltable quadrotor, enabling aggressive aerial manipulation tasks like cartwheel rotations and continuous valve turning with stable omnidirectional control.Link
CompCPZ: Preserving Multi-Modal Intent in Language-Guided Robot ManipulationIntroduces an algebraic layer based on constrained polynomial zonotopes that preserves multiple feasible modes implied by disjunctive language instructions. Wrapped around language-conditioned policies, CompCPZ enables multi-modal feasibility reasoning and outperforms convex-set and multi-peak baselines on ManiSkill3 and transfers to planar real-robot trials.Link
PDDL-ART: Autonomous Symbolic Abstraction From Demonstration For Long-Horizon Robotic Manipulation Using Vision-Language ModelsUniversity of MichiganUses VLMs to autonomously generate PDDL domain and problem files from a single demonstration, natural-language task description, and a library of high-level actions, without templates or fine-tuning. A three-level correction loop plus tool-augmented predicate grounding aligns symbolic abstractions with the demonstrated task, achieving higher success than a baseline VLM planner on complex maintenance and household tasks.Link
FetchMan: Learning Visual Humanoid Loco-Manipulation Policies from Simulated ExperiencesPresents a large-scale sim-to-real pipeline for humanoid loco-manipulation, combining behavior cloning from synthetic demonstrations with Flow-GRPO RL refinement. The resulting FetchMan policy achieves strong performance on a new benchmark and transfers zero-shot to a Unitree G1, reaching and picking a target while walking in novel scenes with over 70% success.Link
