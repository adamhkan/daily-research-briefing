Executive Summary

  • Dexterous and deformable-object manipulation see multiple new benchmarks (LabDex, SoftVTBench) and training pipelines (ADEPT, RoboEdit, Dream2Reward) targeting long-horizon, high-DoF control and rich visuo-tactile feedback.
  • Navigation and motion planning advances span depth-guided collision-aware indoor navigation, autonomous agricultural tractors, and grounded LLM-based or world-model-based trajectory planning for driving.
  • Whole-body and underactuated control methods progress via a behavior world model for humanoids and a control-constrained DDP MPC framework enabling underactuated quadruped balancing and dynamic gaits.
  • Task and layout planning papers address concurrent navigation–fetch coordination for assistive robot dogs and backward layout search for sequence-constrained assembly with explicit motion feasibility checks.
  • Institution-matched work from UC Berkeley and UC San Diego explores LLM-based agentic solutions for contact-rich manipulation and task-agnostic control strategies for soft exosuits.

Revisiting the "Push-T" Robot Manipulation Task with Agentic RoboticsUC BerkeleyUses an LLM coding agent (Claude Code with Fable 5) to autonomously derive algorithms for the Push-T manipulation benchmark without demonstrations. The agent discovers simulation resources online, iteratively optimizes a pushing policy that outperforms diffusion policies trained on 200 demos, and extends to alphabet-shaped blocks and cross-embodiment 3D arm simulations.Link
A Task-Agnostic Control Strategy for Dynamic Assistance with Pneumatically Actuated Soft ExosuitsUC San DiegoIntroduces an inverse-plant control framework for pneumatically actuated upper-extremity soft exosuits that relies only on kinematic sensing. A personalized Hammerstein model (Preisach hysteresis + LTI filter) enables task-agnostic assistance, substantially reducing interaction torques and muscle activation across a range of movement speeds.Link

ADEPT: Accelerating Dexterity via Pre-Training and Post-Training using Reinforcement LearningNVIDIA; University of MichiganProposes ADEPT, a large-scale RL framework that pretrains a generic dexterous policy and then post-trains task-specific behaviors while preserving reusable skills. A joint-space Geometric Fabric and a stabilized post-training recipe enable sim-to-real transfer of visuo-tactile dexterous manipulation on 23- and 29-DoF robot hands at near human speed.Link
Autonomous Agricultural Tractor: Integrated Weed Detection and LiDAR Navigation for Precision Paddy FarmingPresents AgriNav, an autonomous tractor system integrating LiDAR-based navigation with weed/crop perception for paddy fields. A GNSS–IMU–odometry EKF and LiDAR–camera fusion maintain crop-row following through GNSS outages, while asymmetric CNN detectors and conservative weed classification protect rice plants and cut perception load.Link
Real-Time Control-Constrained DDP for Underactuated Balancing of Legged RobotsIntroduces ABC-DDP, a control-constrained Differential Dynamic Programming method using accelerated projected gradients and virtual constraints within a multiple-shooting MPC framework. It handles strong underactuation in real time, enabling a quadruped to achieve static two-leg balancing and varied dynamic gaits under disturbances.Link
DevGRU: Depth-guided Visual Navigation using a Collision-aware Recurrent ModelDevGRU is a depth- and goal-conditioned navigation policy that predicts collision-aware future trajectories with a recurrent action predictor and explicit collision prediction. It significantly outperforms ViNT, NoMaD, and NavDP baselines across multiple indoor scenes while using fewer parameters and achieving faster inference.Link
Backward Layout Search for Sequence-Constrained Robotic AssemblyProposes Backward Layout Search, which assigns initial part poses in reverse assembly order to satisfy a given assembly sequence. By combining geometric, kinematic, grasp, and motion feasibility checks with beam search and collision masks, it reduces evaluations and runtime while producing collision-free layouts validated via forward motion planning.Link
GuideFetch: A Task Coordination Framework for Concurrent Navigation and Object Retrieval in Assistive Robot DogsKarlsruhe Institute of TechnologyGuideFetch coordinates a guide robot and a fetch robot to execute navigation and object-retrieval tasks concurrently from natural language. An LLM produces schedule-conditioned action schemas that are validated against robot capabilities and world state, enabling safe parallel execution that shortens missions without sacrificing reliability.Link
GigaBrain-WBC-0.5: A Behavior World Model for Robust Whole-Body Control with Environment InteractionIntroduces a Behavior World Model for humanoids that jointly predicts actions, states, and future behavior-command distributions using a causal Transformer. Trained with large-scale terrain-annotated motion data, it filters implausible commands online and achieves large gains in terrain interaction, robustness to bad commands, and fall recovery, with successful hardware transfer across platforms.Link
PartialBiGrasp: Inferring Hidden Local Geometry for Bimanual Grasping from Partial ViewsPartialBiGrasp learns implicit local geometry from partial point clouds via convolutional occupancy networks to support dual-arm grasp planning on large, complex objects. It identifies graspable, collision-free contact regions and object thickness, then refines candidate grasp pairs with sampling-based optimization to achieve robust force-closure grasps in simulation and on real robots.Link
DA-WAM: Decision-Aligned Future Latents for Driving World ModelsDA-WAM unifies future representation learning and trajectory planning for autonomous driving by predicting action-conditioned future latents per candidate trajectory. An online encoder–momentum-target setup and factorized scorer keep future predictions decision-informative, yielding state-of-the-art performance on NAVSIM benchmarks.Link
RoboEdit: Turning Human Manipulation Videos into Scalable Robot ExperienceRoboEdit is a human-to-robot video editing suite that reconstructs human hand–object interactions from RGB and retargets them into robot embodiments, generating a 14M-frame dataset across seven robot hands. Its core model, RoboEdit-Trans, enforces temporal coherence and recovers 3D robot hand states, enabling scalable supervision for learning real-world manipulation policies.Link
